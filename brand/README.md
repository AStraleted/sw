# Материалы SQULED Studio

## Логотип

| Файл | Где использовать |
|---|---|
| `logo/logo.svg` | основной знак на светлом фоне |
| `logo/logo-white.svg` | на тёмном фоне |
| `logo/logo-mono.svg` | одноцветный, перекрашивается через `color` |
| `logo/wordmark.svg` | знак вместе с надписью |
| `logo/wordmark-white.svg` | то же на тёмном |
| `logo/logo-512.png` … `logo-64.png` | растровые версии с прозрачным фоном |
| `logo/favicon.svg` | иконка вкладки |

Минимальный размер знака — 16 px. Вокруг оставляйте свободное поле не меньше половины его высоты.
Не растягивайте, не меняйте цвет точки и не добавляйте тени и обводки.

## Баннеры

| Файл | Размер | Для чего |
|---|---|---|
| `banner-1280x720.png` | 1280×720 | ссылка-превью, шапка поста |
| `post-1080x1080.png` | 1080×1080 | пост в соцсети |
| `plans-1080x1080.png` | 1080×1080 | тарифы и цены |
| `cover-1280x320.png` | 1280×320 | обложка канала |

Рядом лежат `.html`-исходники: откройте в браузере, поправьте текст и сделайте снимок экрана,
если понадобится другой вариант.

## Шрифты

- Заголовки — **Lora** (с засечками)
- Текст и интерфейс — **Inter**

Оба лежат в `public/assets/fonts` и свободны для коммерческого использования.
