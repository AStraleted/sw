# SQULED Studio

Рабочее пространство для работы с моделями Claude: чаты, вложения, скиллы, кредиты и администрирование.
Без сборки и без зависимостей — нужен только Node.js 18 или новее.

## Быстрый старт

```bash
npm run setup     # задаст несколько вопросов и создаст .env
npm start         # запустит сервер
```

Откройте адрес, который напечатает сервер: **http://localhost:8787**.

> Открывать `public/index.html` напрямую или через Live Server нельзя — это не статическая
> страница, данные приходят с сервера. Нужен запущенный `npm start` и адрес с портом 8787.

Администратор создаётся при первом запуске из `ADMIN_LOGIN` и `ADMIN_PASSWORD` в `.env`.
Все остальные, кто регистрируется, получают обычные права и бесплатный тариф.
После первого входа смените пароль: **Настройки → Профиль**.

Про публикацию в интернете — отдельная подробная инструкция:
[УСТАНОВКА-НА-СЕРВЕР.md](УСТАНОВКА-НА-СЕРВЕР.md).

Если вы не укажете `API_TOKEN`, сайт запустится в **демо-режиме**: ответы генерируются
локально, ключ не нужен. Так удобно посмотреть интерфейс до подключения API.

## Тарифы и кредиты

| Тариф | Цена | Кредиты | Токены | Скиллы | Предпросмотр | Модели |
|---|---|---|---|---|---|---|
| Бесплатный | — | 25 | ≈ 3 млн | нет | нет | Haiku, Sonnet |
| **PRO** | 250 ₽/мес | 500 | ≈ 60 млн | нет | нет | + Opus |
| **PREM** | 650 ₽/мес | 1100 | ≈ 132 млн | да | да | + Fable |

При оплате на год — скидка 15% (2 550 ₽ и 6 630 ₽).

Кредиты списываются по фактическому расходу: **1 кредит ≈ 120 000 токенов** на самой экономной
модели, а дорогие модели тратят его быстрее по своему множителю (Haiku ×1,5, Sonnet ×2,
Opus ×4, Fable ×8). Токен ответа считается в 5 раз дороже токена запроса. Эти значения
меняются в `.env` (`TOKENS_PER_CREDIT`, `OUTPUT_WEIGHT`) и в `server/config.js` (`PLANS`).

Тарифы выдаются вручную через **Администрирование**: найдите человека в списке, нажмите «…» →
«Выдать тариф». Кредиты и доступ появляются у него сразу. Оплата принимается в Telegram
(`CONTACT_TELEGRAM` в `.env`).

## Режим «Авто»

По умолчанию модель выбирается под задачу, и это главный способ не тратить кредиты зря:

| Что в запросе | Какая модель |
|---|---|
| короткий вопрос, перевод, расчёт | Haiku — быстро и дёшево |
| код, письмо, объяснение, картинка | Sonnet |
| архитектура, разбор ошибки, лендинг, большой PDF | Opus |

Решение принимает сервер, так что подменить выбор из браузера нельзя. Если кредитов осталось
мало, авто само переключается на экономную модель. Выбранная модель подписана под каждым
ответом с пометкой «Авто».

## Возможности

**Чаты.** Поиск по названиям и тексту сообщений (Ctrl+K), переименование, закрепление,
удаление, группировка по датам. Ответ продолжает идти, даже если переключиться на другой чат.

**Ответы.** Markdown с заголовками, списками, таблицами и цитатами. Блоки кода с подсветкой
для 20 языков, копированием, скачиванием файлом и предпросмотром HTML в изолированном окне.
Рассуждения модели показываются отдельным сворачиваемым блоком.

**Сообщения.** Копирование, повтор ответа, редактирование своего сообщения с перегенерацией,
остановка ответа на полуслове.

**Файлы.** Перетаскивание в окно, вставка из буфера, загрузка с прогрессом. Изображения и PDF
уходят модели напрямую, текст и код — как содержимое файла.

**Скиллы.** Шесть готовых наборов инструкций подключаются в один клик: веб-разработка,
программирование, тексты и письма, объяснение, данные и таблицы, планы и решения. С ними
ассистент работает по понятным правилам — выдаёт цельный файл страницы, начинает разбор ошибки
с причины, пишет без канцелярита. Можно добавить и свой скилл ссылкой на репозиторий GitHub
(ищется `SKILL.md`) или просто текстом. Сами скиллы лежат в `server/builtin-skills.js`.

**Кредиты.** Списываются по реальному расходу токенов с множителем модели. Есть график расхода
за две недели и журнал запросов.

**Администрирование.** Список пользователей, выдача тарифов и кредитов, создание аккаунтов,
сброс паролей, роли, блокировка и удаление, журнал всех действий администраторов.

**Файлы и картинки.** Изображения уменьшаются прямо в браузере до 1568 px и сжимаются перед
отправкой — иначе запрос с несколькими фотографиями отклоняется сервисом. На один запрос
отводится 12 МБ вложений; если их больше, старые вложения из переписки не передаются,
а свежие доходят полностью.

## Настройки (.env)

| Параметр | Что делает |
|---|---|
| `API_TOKEN` | Токен сервиса. Пусто — демо-режим |
| `UPSTREAM_URL` | Адрес API |
| `AUTH_HEADER` | `bearer` или `x-api-key` — как передавать токен |
| `PORT`, `HOST` | Порт и адрес. `0.0.0.0` открывает доступ из сети |
| `DATA_DIR` | Папка с данными |
| `ALLOW_REGISTRATION` | `false` закрывает регистрацию |
| `DEFAULT_PLAN` | Тариф нового аккаунта: `free`, `pro` или `prem` |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | Администратор, создаётся при первом запуске |
| `ADMIN_LOGINS` | Дополнительные админы через запятую |
| `COOKIE_SECURE`, `TRUST_PROXY` | Включите оба при работе по https за nginx |
| `MAX_FILE_MB` | Предел размера файла |
| `MAX_HISTORY` | Сколько последних сообщений уходит модели |
| `TOKENS_PER_CREDIT` | Сколько токенов стоит один кредит (по умолчанию 120 000) |
| `OUTPUT_WEIGHT` | Во сколько раз токен ответа дороже токена запроса |
| `CONTACT_TELEGRAM` | Telegram для оплаты тарифов |
| `YEAR_DISCOUNT` | Скидка при оплате за год, проценты |

Модели, тарифы и уровни силы рассуждений перечислены в `server/config.js` — там же множители
списания и состав каждого тарифа.

## Публикация в интернете

1. Поставьте Node.js 18+ на сервер и скопируйте туда папку проекта.
2. Выполните `npm run setup`, укажите токен и ответьте «да» на вопросы про сеть и https.
3. Запустите как службу — пример для systemd лежит в `deploy/squled.service`:

   ```bash
   sudo cp deploy/squled.service /etc/systemd/system/
   sudo systemctl enable --now squled
   ```

4. Поставьте перед ним nginx с сертификатом — пример в `deploy/nginx.conf`.
   Важно: в нём отключена буферизация, иначе ответ будет приходить не потоком, а целиком.

После публикации закройте регистрацию (`ALLOW_REGISTRATION=false`) и заводите пользователей
сами, иначе вашим ключом сможет пользоваться любой, кто найдёт адрес.

## Как это защищено

Главное правило: **браузер ничего не решает**. Все ограничения проверяются на сервере, поэтому
через консоль разработчика или подменённый запрос их не обойти.

- Тариф, доступные модели, скиллы, предпросмотр и размер файла проверяются при каждом запросе.
  Попытка взять закрытую модель вернёт отказ, даже если подменить значение в браузере.
- Кредиты и подписки меняет только администратор. В свой профиль пользователь может записать
  лишь имя, настройки и пароль.
- Предпросмотр страниц собирается на сервере и отдаётся по одноразовой ссылке, живущей 10 минут,
  в песочнице без доступа к cookie и API сайта. Без тарифа ссылка просто не выдаётся.
- Пароли хранятся как scrypt-хеш с солью, в открытом виде нигде не появляются.
- Сессия — случайный токен в cookie `HttpOnly`, `SameSite=Lax`, привязанный к отпечатку браузера:
  украденная cookie на другом устройстве не сработает. Больше 10 сессий на аккаунт не живёт.
- Изменяющие запросы требуют заголовок `X-Requested-With`, так что чужой сайт их не отправит.
- Ограничение частоты: вход (10/мин), регистрация (5/час), сообщения (20/мин), файлы (40 за 10 мин),
  установка скиллов (20 за 10 мин). Одновременно у одного человека идёт не больше двух ответов.
- Модель не может потратить больше, чем осталось кредитов: предел ответа считается заранее.
- Токен API живёт только на сервере и в браузер не попадает.
- У страницы строгий `Content-Security-Policy`.
- Загруженные файлы отдаются только их владельцу; HTML и SVG — всегда на скачивание,
  чтобы чужой скрипт не выполнился на домене сайта.
- Все действия администраторов пишутся в журнал: кто, когда, кому и что изменил.

## Резервное копирование

Всё хранится в папке `data`: `db.json` (аккаунты, скиллы, журнал), `chats/` (переписка)
и `uploads/` (файлы). Достаточно скопировать эту папку.

## Про рассуждения моделей

Новые модели используют `thinking: adaptive` вместе с `output_config.effort`, старые — бюджет
в токенах. Сервер пробует режимы по очереди и запоминает тот, который принял API, поэтому
при смене версии API настраивать ничего не нужно.
